AbortController & Fetch API

  1. AbortController - AbortController is a built-in browser API that allows you to abort one or more asynchronous tasks (such as fetch requests) on demand. It provides a signal property (an instance of AbortSignal) that is passed into fetch(), and an abort() method to cancel the operation.

  2. Why do we need AbortController? - 1. Canceling in-flight requests: If a user navigates away from a page or closes a modal, pending network requests can be canceled to save bandwidth and memory.
    2. Handling Race Conditions: In search/autocomplete inputs, rapid keystrokes trigger multiple API requests. If an earlier request takes longer to respond than a later one, it can overwrite the latest search results. Aborting the previous in-flight request prevents race conditions.
    3. Implementing Request Timeouts: Easily cancel a request if it exceeds a specified duration.

  3. Handling the Abort Error - When a request is aborted, the fetch promise rejects with a DOMException whose name is 'AbortError'. In catch blocks, we check if (error.name === 'AbortError') to avoid logging aborted requests as real errors.
