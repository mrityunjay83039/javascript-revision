Modern Browser Observer APIs

Observer APIs asynchronously observe changes without polling or binding heavy scroll/resize event listeners, preventing layout thrashing and jank.

  1. 1. IntersectionObserver

    Asynchronously observes changes in the intersection of a target element with an ancestor element or top-level document's viewport.
    Top Use Cases: Image lazy-loading, Infinite scrolling (triggering next page fetch when bottom sentinel element enters viewport), and tracking ad viewability.

  2. 2. ResizeObserver

    Invokes a callback whenever a target element's content rectangle or border-box changes size.
    Top Use Cases: Container queries, responsive component charts, dynamic sidebar adjustments without listening to window resize.

  3. 3. MutationObserver

    Listens for direct mutations made to the DOM tree (child node additions/removals, attribute updates, text content modifications).
    Top Use Cases: Microfrontends, third-party script integrations, undo/redo systems, accessibility auditors.
