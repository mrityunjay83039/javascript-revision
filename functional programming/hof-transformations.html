Higher-Order Functions (HOFs) & Array Immutability Methods

  1. Higher-Order Function (HOF) - A function that receives another function as an argument, returns a function, or does both. Common examples include map, filter, reduce, and custom functions like debouncers/throttlers.

  2. Core Array Transformations - 1. map(): Transforms each item and returns a brand-new array of identical length.
    2. filter(): Filters items based on a boolean condition and returns a new filtered array.
    3. reduce(): Accumulates array elements down to a single value (number, object, array).
    4. flat(depth): Creates a new array with sub-array elements concatenated into it up to the specified depth (use Infinity for complete flattening).
    5. flatMap(): First maps each element using a mapping function, then flattens the result by depth 1. It is more efficient than calling .map().flat().

  3. Modern Immutability Methods (ES2023 / ES14) - In functional programming and state management (e.g. React/Redux), mutating state directly causes subtle bugs. Traditional methods like sort(), reverse(), and splice() mutate the original array in place.
    ES2023 introduced non-mutating alternatives:
    - toSorted(): Returns a new sorted array without altering the original.
    - toReversed(): Returns a new reversed array without altering the original.
    - toSpliced(): Returns a new array with added/removed elements without mutating the original.
    - with(): Returns a new array with a single element updated at a given index.
