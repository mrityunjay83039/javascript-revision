Metaprogramming & Advanced Primitives

  1. 1. Proxy and Reflect

    - Proxy: Wraps a target object and intercepts fundamental operations like property reading (get), writing (set), deletion, or function calls.
    - Reflect: Companion built-in object that provides the default implementation for intercepted operations. Using Reflect.get/set ensures correct this binding (receiver) across prototype chains.
    - Under the Hood in State Libraries: Vue 3, MobX, and Immer use Proxy to observe property reads (dependency tracking) and property writes (triggering reactive re-renders).

  2. 2. Symbol and Well-Known Symbols

    - Symbol() creates guaranteed unique, immutable primitive identifiers for object properties.
    - Well-Known Symbols: JavaScript exposes internal language behaviors via symbols. The most famous is Symbol.iterator, which specifies the default iterator for an object.

  3. 3. Iterators and the Iterable Protocol

    - Iterable Protocol: An object is iterable if it implements a method at key [Symbol.iterator].
    - Iterator Protocol: The iterator object must provide a next() method returning { value: any, done: boolean }.
    - Enables native support for for...of loops, array destructuring [a, b], and the spread operator [...iterable].

  4. 4. Generators (function* / yield)

    - Generators are functions that can pause execution midway (using yield) and resume later when .next() is called.
    - Lazy Evaluation: Generates values on-demand without calculating or storing everything in memory upfront (e.g. infinite sequence generation, async task runners).
