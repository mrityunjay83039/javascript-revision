Function Constructor and Inheritance

  1. Constructor Function - A constructor function is a regular function used as a blueprint to create multiple objects with similar properties and methods. By convention, it starts with a capital letter and is invoked with the new keyword.

  2. What the new Keyword Does - 1. Creates a new empty object {} in memory.
    2. Links the object's prototype to the constructor's prototype (obj.__proto__ = Constructor.prototype).
    3. Binds this inside the constructor to this new object.
    4. Executes constructor code and returns the new object automatically.

  3. Inheritance with call() (Constructor Stealing) - To inherit properties from another constructor, we call Person.call(this, fname, lname, age) inside Students. This passes the new student instance context to Person, initializing the inherited properties.

  4. Methods in Constructor vs Prototype - Defining methods inside the constructor (like this.greeting) creates a separate copy of that function for every instance in memory. To optimize memory, methods should be attached to Person.prototype so all instances share a single copy via the prototype chain. 

        function Person(fname, lname, age){
            this.fname = fname,
            this.lname = lname,
            this.age = age
    
            this.greeting = function(){
               return `hello ${fname}`
            }
        }
    
        function Students(fname,lname,age,psp,batch){
            Person.call(this,fname,lname,age)
            this.psp = psp,
            this.batch = batch
        }
    
        let student1 = new Students('Mrityunjay','Mishra',27,81.00,'full stack')
